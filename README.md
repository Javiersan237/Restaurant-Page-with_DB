\# 🍽️ ÉLYSÉE Reservas



\[!\[Build Status](https://img.shields.io/badge/build-passing-brightgreen)]()

\[!\[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

\[!\[Version](https://img.shields.io/badge/version-0.1.0-blue)]()



Sistema de gestión de reservas para el restaurante \*\*ÉLYSÉE\*\*. Permite administrar mesas, horarios, clientes y reservas desde una interfaz web moderna.



\## 🛠️ Stack Tecnológico



| Capa | Tecnología |

|------|-----------|

| Backend | Node.js + Express |

| Base de datos | SQL Server 2019+ |

| Frontend | React |

| Autenticación | JWT |



\## 📁 Estructura del Proyecto



&#x20;   Restaurant-Page-with\_DB/

&#x20;   ├── backend/          # API REST (Node.js + Express)

&#x20;   ├── frontend/         # Interfaz de usuario (React)

&#x20;   ├── database/         # Scripts SQL, migraciones y seeds

&#x20;   ├── docs/             # Documentación detallada

&#x20;   └── .github/          # Templates y workflows



\## 📋 Requisitos Previos



\- \*\*Node.js\*\* >= 18.x

\- \*\*npm\*\* >= 9.x

\- \*\*SQL Server\*\* >= 2019

\- \*\*Git\*\*



\## 🚀 Instalación Paso a Paso



\### 1. Clonar el repositorio



&#x20;   git clone https://github.com/Javiersan237/Restaurant-Page-with\_DB.git

&#x20;   cd Restaurant-Page-with\_DB

&#x20;   git checkout develop



\### 2. Configurar variables de entorno



&#x20;   cp .env.example .env



\### 3. Instalar dependencias



&#x20;   cd backend \&\& npm install

&#x20;   cd ../frontend \&\& npm install



\## ▶️ Cómo ejecutar el proyecto



\*\*Backend:\*\*



&#x20;   cd backend

&#x20;   npm run dev



\*\*Frontend:\*\*



&#x20;   cd frontend

&#x20;   npm start
